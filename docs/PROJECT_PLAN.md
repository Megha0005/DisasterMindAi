# DisasterMind AI – Project Plan

Planned syllabus modules:
1. Bayesian Networks and conditional independence
2. Markov Networks, factors and latent variables
3. Restricted Boltzmann Machines
4. Markov Chains, Gibbs Sampling and Contrastive Divergence
5. Autoencoders, VAEs, autoregressive density estimation, MADE and GANs

Initial application scope: India-focused flood analysis using public historical and environmental datasets. Dataset provenance, temporal/geographic alignment, label quality and leakage controls must be documented.
